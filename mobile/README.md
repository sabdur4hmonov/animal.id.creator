# BioLivestock Capture

Android/iOS scaffold generated by flutter create. See the repository README for backend setup, device URLs, permissions, QC and model limitations.

Testing uses a physical Android phone over USB, not an emulator. Follow the [repository README](../README.md)
for `flutter pub get`, `adb reverse tcp:8000 tcp:8000` and `flutter run` with **API_BASE_URL, API_TOKEN and
OPERATOR_ID**. Re-run adb reverse after reconnecting the phone. `flutter analyze` and `flutter test`
validate host code; a successful APK build does not verify camera/permissions/GPS on a phone.

Connect once to cache enabled species/QC settings, then capture offline. Local-QC-passing originals
are retained in a durable queue across restart. Use Upload pending captures after reconnecting and
Review saved upload receipts to copy request-key/UUID mappings. Do not uninstall/clear app storage
before upload and backup. See [collection/recovery instructions](../docs/COLLECTION_RELIABILITY.md).
