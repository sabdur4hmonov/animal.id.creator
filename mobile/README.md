# BioLivestock Capture

Android/iOS scaffold generated by flutter create. See the repository README for backend setup, device URLs, permissions, QC and model limitations.

Testing uses a physical Android phone over USB, not an emulator. Run flutter pub get, then adb reverse tcp:8000 tcp:8000, then flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000. Re-run adb reverse after reconnecting the phone. flutter analyze and flutter test validate the Dart code.
